REXRUN 건강 데이터 사용 안내

2026년 10월 26일 기준 개발 테스트용 앱입니다. 건강 점수·추이는 데모입니다. 생활습관·신체 정보로 혈압 단계의 참고 분포를 추정하는 M1-S 모델과 M2 참고 항목, 전날 실천 기록에 따른 규칙 기반 퀘스트 추천을 사용합니다. 측정 혈압 밴드 판정은 별도 서비스 연결 전입니다. 참고 분석은 진단이나 미래 발병 확률이 아닙니다.

계정과 서버 저장

로그인은 Supabase Auth에서 처리합니다. 사용자가 저장에 동의하면 이름·아바타·건강 설문·복약 일정과 기록·걸음 수·퀘스트·게임 진행을 HTTPS로 AWS 수집 API(시드니)에 보내고 Supabase PostgreSQL(서울)에 계정별로 저장합니다. 사용자는 본인 기록만 조회할 수 있습니다. 전송 동의를 끄면 이 기기에서 이후 전송을 중단하며 기존 서버 기록은 유지됩니다.

생활습관 참고 분석

저장한 나이·성별·키·몸무게·공복 혈당·생활습관·가족력·혈압 입력 및 혈압약 복용 여부를 AWS 모델 API(시드니)에서 처리합니다. 혈압 입력 또는 혈압약 복용 시에는 이 모델로 추정하지 않습니다. 이름·특수 이력 자유 문구·게임 기록은 M1-S 입력으로 사용하지 않습니다. 현재 결과는 요청 시 계산하며 입력값·결과를 서버 로그에 남기거나 별도 결과 이력으로 저장하지 않습니다. 서버 저장 동의를 끄면 참고 분석 요청도 중단됩니다.

걸음 수·수면 읽기

Health Connect에서 오늘의 걸음 수를 읽어 6,000걸음 퀘스트에 반영합니다. 건강 데이터 쓰기 권한은 요청하지 않습니다. 폰·워치 중복 기록은 Health Connect 집계를 사용합니다. 앱 화면을 사용하는 동안 5초마다 확인합니다. Android 14 이상에서 신체 활동 및 Health Connect 백그라운드 읽기를 추가로 허용하면 상태 알림과 함께 백그라운드에서 30초 주기로 조회합니다. 이 기능은 현재 걸음 수만 읽으며 수면을 백그라운드에서 추가로 조회하지 않습니다. 로그아웃·연결 끄기·앱 작업 제거 시 서비스를 중단합니다. 강제 종료·절전 상태에서는 지연되거나 중단될 수 있습니다.

수면 퀘스트 연결을 선택하면 수면 읽기 권한만 추가로 요청합니다. 오늘 끝난 수면 단계에서 잠든 시간을 계산하며 깨어 있음·침대에 머문 시간과 중복 구간은 제외합니다. 인증 후 완료한 수면 시간은 게임 기록에 반영되고 저장 동의가 있는 경우 기존 서버 저장 경로를 따릅니다.

선택적 식단 사진 분석

사진 전송에 별도로 동의하고 분석을 요청하면 사진을 분석 서버와 OpenAI에 전송해 음식명과 예상 제공량을 확인합니다. 분석 서버는 EXIF 위치·기기 정보를 제거한 뒤 처리하며 사진을 영구 보관하지 않습니다. 외부 AI 제공자의 데이터 처리 정책은 해당 제공자에게 적용됩니다. 사진 인증만 이용하면 이 분석 전송은 실행하지 않습니다.

사용자가 확인한 음식명·중량·영양 추정치·끼니·날짜는 기기에 계정별로 저장합니다. 기록 화면에서 삭제할 수 있으며 다른 기기로 자동 동기화되지 않습니다. 사진과 AI 전송 동의는 기록에 포함하지 않습니다. 현재 영양값은 F6 개발용 샘플 DB 기반 참고치이며 실제 섭취량이나 질환에 맞는 식단 여부를 확정하지 않습니다.

퀘스트 사진·동작 인증

식사와 복약·투약은 앱에서 촬영한 사진 제출, 물 마시기는 기기 내 카메라 동작 인식을 확인합니다. 사진 인증만 이용하는 경우 사진과 영상은 서버로 전송하거나 기기에 영구 저장하지 않습니다. 제출 사진의 음식·약 종류, 실제 복용 사실, 섭취량을 AI로 판정하는 기능은 아닙니다. 샘플 시연은 퀘스트 인증이나 보상에 사용하지 않습니다.

기기 저장과 알림

게임과 복약 기록·계정별 전송 대기 기록은 기기에 보관하고 연결 복구 후 전송합니다. 앱 자체의 암호화 저장소는 아닙니다. 사용자가 켠 복약 알림은 Android에 예약합니다. 퀘스트 푸시를 켜면 기기 토큰을 계정에 연결하고 Firebase Cloud Messaging으로 일반적인 완료 알림을 보냅니다. 알림에 약 이름·용량·건강 수치를 표시하지 않습니다.

카메라와 위치

카메라 영상과 인증만을 위한 사진은 서버에 전송하지 않습니다. 날씨 기능에 동의하면 반올림한 좌표만 Open-Meteo로 보내며 건강정보는 포함하지 않습니다.

로그아웃과 권한

로그아웃하면 게임·걸음 동기화를 중단하고 현재 화면과 복약 예약 알림을 초기화합니다. 계정별 전송 대기 기록과 서버 기록은 삭제되지 않습니다. Health Connect 앱 권한에서 걸음 수 읽기를 철회할 수 있고, Android 설정에서 알림 권한을 관리할 수 있습니다. REXRUN의 연결 끄기는 자동 동기화만 중단합니다. 계정·서버 기록 삭제를 위한 앱 내 기능은 아직 제공하지 않는 테스트 버전입니다.
