# 전면 카메라 CV 과정 인식 1차 프로토타입

개발일: 2026-10-26. 로컬 경로: `/cv` (`?task=water`, `?task=medicine`, `?task=injection`). 2026-10-26에 기존 native 1.5.0용 서명 OTA **1.5.2**와 [공개 HTTPS 테스트](https://d4vy5vn0lhbgi.cloudfront.net/cv)에 배포했다. 로그인/데모 체험 후 **Quest → 전면 카메라 CV 테스트**로 진입한다. 1.5.0 설치 앱은 마이페이지의 앱 업데이트에서 확인할 수 있다.

## 구현 범위

전면 카메라 원본 화각에서 얼굴·손·컵/병을 추적하고, 시간에 따른 순서를 규칙으로 판정한다. 기존 픽셀 UI와 MediaPipe 로컬 추론을 재사용한다. 새로운 알약 분류 모델을 학습한 결과가 아니다.

| 모드                | 확인하는 순서                                                                                           | 확인할 수 없는 것                              |
| ------------------- | ------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| 주사·인슐린 손 동작 | 화면에서 부위 지정 → 부위 밖의 손 → 부위 근처에서 머묾 → 손 떼기                                        | 펜·주사기 식별, 바늘 삽입, 실제 약물 주입·용량 |
| 물 마시기           | 컵을 입 아래에 표시 → 입에 접근 → 1.1초 유지 → 컵 내림 및 재탐지                                        | 물/다른 음료 구분, 실제 삼킴, 섭취량           |
| 경구 복약           | 준비 확인 → 엄지·검지로 집은 손을 입으로 이동 → 0.45초 유지 → 손 내림 → 30초 이내에 새 마시기 순서 완료 | 알약 존재·종류·용량, 실제 복용/삼킴 여부       |

촬영은 스마트폰을 눈높이에 세우고 한 사람의 얼굴·손·컵을 함께 담는 구도를 가정한다. 물과 함께 먹는 알약·캡슐의 순서만 다룬다. 물 없이 먹는 제형, 씹거나 혀 밑에 놓는 과정은 경구 복약 모드의 판정 대상이 아니다. 검증을 위해 약을 추가로 복용하지 않는다. 빈손·빈컵 연습도 같은 동작으로 감지될 수 있다.

## 처리 구조

1. `getUserMedia`: 전면 카메라(`facingMode: user`), 음성 비활성화. 미리보기와 입력 모두 전체 원본 화각을 비율 유지하여 표시/축소한다.
2. 물/경구 복약에서는 Worker에서 Face Landmarker와 Hand Landmarker를 실행한다. 주사 모드는 얼굴이 필요 없어 Hand Landmarker만 실행하고, 사용자 지정 부위와 손바닥 중심의 움직임을 비교한다. EfficientDet Lite0는 cup/bottle만 탐지하며 물/경구 복약 두 과정에서 사용한다.
3. 픽셀 좌표를 얼굴 폭으로 정규화한다. 복약 손은 엄지·검지 중점, 집기 간격은 손목~중지 MCP 길이로 정규화한다. 화면 밖 랜드마크는 집기 판단에 사용하지 않는다.
4. `ProcessDetector`가 손/마시기 감지기를 순차 실행한다. 중복·역순 프레임, 다른 타임스탬프, 얼굴 추적 변경, 1.2초 초과 얼굴 이탈/영상 중단, 30초 초과 순서 지연을 검사한다.
5. 성공/60초 관찰 종료/사용자 중단/페이지 숨김/언마운트/오류 시 카메라 트랙을 정지하고 Worker를 종료한다.

목표 입력은 최대 10fps, 컵 탐지는 최대 5fps다. 추론 중에는 프레임을 쌓지 않는다. 5fps 입력까지 합성 시퀀스로 검증했으며, 심하게 느린 2.5fps 시퀀스는 완료되지 않는다. 실제 휴대폰 성능 수치는 아직 측정하지 않았다. 화면의 처리 지연은 프레임 전송과 추론을 포함하며, 유효 관찰 비율은 정확도/확률이 아니다.

## 주요 초기 규칙

| 항목                                 | 초기 값                    |
| ------------------------------------ | -------------------------- |
| 손 입 근처 진입 / 멀어짐             | 얼굴 폭의 0.28 / 0.85      |
| 집기 간격 / 손바닥 길이              | 0.45 이하                  |
| 손 입 근처 유지                      | 450ms                      |
| 컵 입 근처 진입 / 유지 허용 / 멀어짐 | 얼굴 폭의 0.2 / 0.3 / 0.45 |
| 컵 입 근처 유지                      | 1100ms                     |
| 시작·복귀 안정 시간                  | 400ms                      |
| 관찰 유효 비율                       | 80% 이상                   |
| 컵 신규 획득 / 연속 탐지 점수        | 0.40 / 0.25                |

이 값은 실제 사용자 데이터로 보정한 임상/인식 성능 기준이 아니다. 복약의 컵 단계는 손 단계를 통과한 뒤 새로 시작하여 앞선 마시기 동작을 재사용하지 않는다. 물/경구 복약에서는 여러 얼굴이 보이면 완료하지 않는다. 얼굴 추적의 연속성 검사는 신원 인식이 아니다.

## 결과와 기존 퀘스트 분리

- 카메라 결과: `inputSource: camera`, 물/경구 복약은 `detector: process_rules_v2`, 주사 손 동작은 `detector: injection_rules_v1`. 모두 `verificationLevel: experimental_process`다.
- 합성 시연: `inputSource: sample`. 실제 영상이나 모델 예측의 정확도를 증명하지 않는다.
- JSON 저장은 결과·시간·설정/모델 버전·단계 전이·사용자가 선택한 시도 라벨만 포함한다. 프레임/랜드마크·음성은 저장하지 않는다. 다운로드는 사용자가 명시적으로 누를 때만 한다.
- 실험 결과는 기존 퀘스트 증빙 저장소에서 거부하며, 복약 기록/보상을 만들지 않는다. 기존 물 인증 및 복약 사진 흐름은 유지한다.
- 사진/영상은 서버로 보내지 않는다. 모델 자산은 앱의 정적 파일에서 불러온다. 카메라는 HTTPS 또는 localhost와 사용자 권한이 필요하다.

## 검증과 다음 데이터 수집

자동 검사는 순서, 타임아웃, 중단, 집기 형태, 컵 고정, 마시기만/손 동작만 수행, 전체 화각, 5fps 처리, 실험 결과의 퀘스트 격리를 확인한다. 브라우저에서는 합성 시연 3개와 물/경구 복약용 세 모델 및 주사 모드의 손 모델에 빈 영상 스트림을 입력하는 검사를 실행한다. 빈 영상 검사는 모델 로드/추론/음성 미사용/전면 카메라 요청/트랙 해제를 확인하지만 사람 동작의 양성 인식률은 측정하지 않는다.

실사용 전 동의한 참여자의 스마트폰 테스트 자료가 필요하다. 참여자 단위로 학습/보정/평가를 분리하고, 같은 사람·같은 영상의 인접 프레임을 서로 다른 평가군으로 나누지 않는다. 원본 영상 수집은 별도 동의와 보관 정책을 정한 뒤 진행하며 이 프로토타입은 자동 수집하지 않는다.

| 평가 축        | 포함할 사례                                                                                                |
| -------------- | ---------------------------------------------------------------------------------------------------------- |
| 양성           | 컵·병 마시기, 알약을 집는 손→입→물 순서, 왼손/오른손, 속도 차이                                            |
| 음성/유사 동작 | 컵 들기만, 얼굴 만지기, 전화, 식사, 손만 입에 가져감, 물만 마심, 순서 반전, 빈손·빈컵 연습                 |
| 환경           | 전면 카메라 기종·화각, 세로/가로, 조도·역광, 안경·가림, 거리, 컵 모양/투명도, 배경의 다른 사람             |
| 품질/측정      | 과정별 precision/recall/F1, 오탐/시간, 미완료율, 단계별 지연, FPS 및 p50/p95 처리 시간, 사용자/기기별 결과 |

빈손·빈컵과 실제 섭취를 동작만으로 구분하지 못하는 점을 데이터 라벨과 결과에 명시한다. 알약 존재까지 구분하려면 손 안의 작은 물체를 볼 수 있는 촬영 구도와 별도 탐지 데이터/모델 검증이 필요하다. 실제 삼킴 확인은 이 전면 영상 규칙만으로 보장하지 않는다.

공식 구현 자료: [MediaPipe Hand Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/web_js), [Object Detector](https://developers.google.com/edge/mediapipe/solutions/vision/object_detector/web_js).

## 주사·인슐린 모드의 범위

추가 요청으로 `/cv?task=injection`에 자가 투약 부위의 손 동작 프로토타입을 포함했다. 카메라를 고정한 뒤 영상 속 관찰 부위를 누른다. 원본 화각과 미러링, 레터박스를 역변환하여 부위를 표시한다. 키보드 사용자는 화면 중앙 선택 버튼을 사용할 수 있다. 부위를 다시 선택하면 이전 순서는 버린다. 얼굴을 촬영하지 않아도 손바닥 랜드마크만으로 처리한다.

지정 원 바깥에서 400ms 관찰 → 안으로 접근 → 안에서 1200ms 관찰 → 바깥으로 떨어져 400ms 관찰을 검사한다. 1200ms는 시험용 영상 관찰 기준이며 주사 유지 시간이나 투약 방법이 아니다. 800ms 넘게 손이 사라지거나 큰 손 위치 전환이 있으면 순서를 초기화한다. 스마트폰이나 몸의 위치가 달라지면 사용자 지정 부위도 다시 잡아야 한다.

일반 사물 모델에 주사기/펜 탐지를 추가한 것이 아니다. `kind: injection_site_hand_process`와 `toolDetected: false`, `needleInsertionVerified: false`, `doseVerified: false`로 내보낸다. 부위를 만지는 동작이나 바늘 없는 연습도 같은 결과가 될 수 있다. 실제 투약 여부로 해석하지 않으며 퀘스트·복약 기록에 연결하지 않는다. 다음 단계에는 펜/주사기 종류별 근접 영상, 도구 없는 유사 동작, 손에 가려짐을 포함한 동의 기반 평가 자료와 별도 도구 탐지 모델이 필요하다.

사용 도구는 인슐린 펜/일반 주사기를 모두 선택할 수 있다. 이 선택은 `userDeclaredTool`로 기록하는 사용자 라벨이며 자동 식별 결과가 아니다. 두 도구 모두 같은 지정 부위 손 동작 규칙을 사용한다. 도구별 민감도·오탐률은 아직 측정하지 않았다.
