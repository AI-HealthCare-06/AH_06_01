브랜치: `feature/pixel-adventure-device-quests`. 공개 웹과 Supabase galaxy-test/native 1.5.0 채널에 **서명 OTA 1.5.6**을 게시했다. 연결된 Galaxy S25+에서도 **재설치 없이 1.5.6** 적용을 확인했다. 네이티브 APK는 1.5.0(10)을 유지한다. 다음 웹 배포 버전은 1.5.7 이상이다.

수면 기록을 수정해 EXP를 반복 수령할 수 없다. 예전 수면 퀘스트 보상을 받은 날짜에는 새 보너스를 중복 지급하지 않는다. 누락된 시간·점수를 임의로 채우거나 과거 보상을 소급 재계산하지 않는다. 기존 잔액과 계정 동의 설정을 유지한다.

## 분석 데이터

취침·기상 시각 및 0~10 원본 응답은 계정의 일일 서베이에 보관한다. 수면 시간은 기존 대시보드·모델 입력을 사용한다. 현재 모델의 증상 입력은 불리언이므로 0은 없음, 1~10은 있음, 모름은 결측으로 전달한다. 이 변환은 증상 유무를 연결하는 방식이며 점수에 대한 임상 임계값을 새로 만든 것이 아니다. 모델 학습·가중치·임계값은 이번 작업에서 바꾸지 않았다. 서버 저장 동의와 RLS를 유지한다.

## 검증과 배포

- 전체 프런트엔드 단위 테스트 **292개**, 관련 Playwright 시나리오 **31개** 통과. 기본 실행 30개와 별도 인증 실행 1개다. 전체 E2E 묶음을 실행한 것은 아니다.
- lint, format:check, 타입 검사와 프로덕션 빌드를 통과했다. 320/390/430px 및 짧은 화면에서 설문·툴팁·선택 목록·마이페이지·상점을 확인했다.
- Supabase 마이그레이션 `20261027065115_ux_survey_quests_notifications`를 적용했다. 합성 계정과 롤백 트랜잭션으로 실제 퀘스트 완료 알림 내용을 검증했다. 메인 카탈로그 4개, 카탈로그·알림 테이블 RLS, 트리거 함수의 익명/일반 사용자 직접 실행 차단을 확인했다. 기존 사용자 알림을 보내거나 기록을 다시 쓰지 않았다.
- DB advisor 오류는 없고 기존 비밀번호 유출 방지 설정 경고는 이번 범위에서 변경하지 않았다. 기존 이력의 타임스탬프 차이 때문에 이번 SQL만 적용 후 공식 CLI로 해당 마이그레이션 이력을 기록했다.
- OTA **308개 경로 / 278개 고유 파일 / 141,442,207바이트** 전체 서명·SHA-256 확인. 공개 웹 308개 파일 게시 및 CloudFront 무효화를 완료했다.
- 공개 웹의 합성 계정으로 취침 23:00→기상 06:00, 0/10 응답, 수면 보너스, 새로고침 유지, 서버 스냅샷, 모델 응답의 일일 날짜를 확인했다. 합성 계정 원본 스냅샷을 복원했다.
- 연결 Galaxy S25+ (SM-S936N)의 기존 native 1.5.0(10) 위에서 OTA 1.5.6, 로그인·잔액 보존, 짧은 동기화/업데이트 행, Android 상태바, 서베이 항목 전환·단위·시간 선택기를 직접 확인했다.
- 실제 하드웨어 Back 첫 클릭 토스트와 두 번째 클릭의 액티비티 종료를 확인하고 앱을 다시 열었다. 실제 계정의 설문·복용 기록은 제출하지 않았다. 확인용 초안은 닫아 폐기했고 점검용 화면 켜짐 설정과 임시 XML을 원복·정리했다.
