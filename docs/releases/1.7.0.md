# REXRUN 1.7.0 (APK versionCode 13)

- 대시보드 첫 화면의 최신 M1·M2 분석 요약과 선택 기간의 6개 핵심 지표, 혈압·혈당·맥박 추이, 실천 캘린더·활동/좌식·수면 리듬·식단 영양 구성·원자료 조회.
- 고정 질환 확률/퀘스트 효과 예시 제거, 중복 선택일 기록 접기, 프로필 혈압 바로 기록 유지.
- 스킨·공룡 터치 드래그, 포인터 캡처 이전, 연속 선택·무한 루프·세로 스크롤·저장 복원 보완.
- 합성 90일 서베이·활동·복약 및 180끼 식단을 가진 시연용 민준. 모델 결과는 실제 해당 합성 입력으로 계산한 결과 재생으로 표시하며 입력 변경 시 무효화.
- 식약처 식품 DB와 고해상도/불확실 영역 재검토를 이용한 식단 분석 및 확인·수정 흐름. 새 APK의 CameraX/MediaPipe 전면 카메라 추론과 물 마시기 동작·완료 피드백.

APK native 1.7.0 (versionCode 13), 웹 배포선 1.7. 기존 native 1.5.0/1.5.1/1.5.2는 서명된 OTA로 웹 변경을 받고 네이티브 플러그인이 없으면 Worker 카메라를 유지한다. 새 네이티브 추론에는 새 APK 덮어설치가 필요하다. 기존 서명 계보·OTA 개인키와 공개 채널을 유지한다.

시연 기록은 실제 환자 기록이나 치료 효과를 나타내지 않는다. 전용 알약·주사 도구/동작 학습 데이터는 아직 없으며 실제 삼킴·용량·투약 완료의 판정으로 사용하지 않는다.

구버전 식단 클라이언트는 기존 DEV 코드 응답을 유지하고, 새 클라이언트는 catalog_version으로 공식 MFDS 카탈로그를 요청한다. 알 수 없는 버전은 모델 호출 전에 거절한다.
