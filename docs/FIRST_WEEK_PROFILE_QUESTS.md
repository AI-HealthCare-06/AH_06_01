# 첫 로그인 설문과 첫 주 기록 퀘스트

2026-10-28 · 작업 브랜치 `feature/pixel-adventure-device-quests`

## 사용자 흐름

- 최초 로그인: 기본 정보 → 혈압 정보 → 입력 확인, 총 3단계.
- 기본 정보: 이름·나이·성별·키·몸무게. 혈압 정보: 최근 혈압 또는 모름, 고혈압 진단·치료 상태.
- 공복 혈당·지병·생활습관·가족력·복약 등록은 최초 가입 필수 단계에서 분리했다. 입력하지 않은 혈당·흡연·가족력 등은 null/모름으로 보관한다.
- 공룡 선택을 마치면 홈의 첫 주 기록 안내 또는 퀘스트 탭의 별도 섹션에서 두 퀘스트를 시작한다.
- 지병 기록하기: 지병 → 그 밖의 만성질환 → 특수 이력·치료 상태 → 약/영양제와 시간 → 확인.
- 생활습관 기록하기: 생활습관 → 음주 → 추가 분석 정보 → 가족력 → 확인.
- 기존 마이페이지의 전체 건강 정보 수정과 항목별 바로가기도 유지한다. 일부 항목만 수정한 경우 방문·제출하지 않은 기록 퀘스트를 완료 처리하지 않는다.

## 보상 규칙

- 각 퀘스트는 최초 로그인 시각부터 정확히 7×24시간 안에 완료하면 고정 200 EXP를 한 번 지급한다. 마감 시각과 동일하거나 이후에는 EXP를 지급하지 않는다.
- 기한 이후에도 정보를 기록·수정하고 퀘스트를 완료할 수 있다. 재제출·다음 날·다시 로그인·JSON 복원으로 추가 보상을 지급하지 않는다.
- 기존 레벨업 골드 계산을 사용한다. 일일 4개 메인 퀘스트, 일일 완료·주간 달성 조건 및 버프에는 이 두 퀘스트를 추가하지 않는다.
- 기존 상세 가입을 완료한 사용자와 기존 합성 데모는 두 기록을 완료로 이관하며 EXP를 소급 지급하지 않는다.
- 보상은 입력한 수치의 정상 여부와 관계없다. 없음·모름도 유효한 기록으로 제출할 수 있다.

## 저장과 계정 분리

`game.profileQuests`에 최초 시작 시각과 항목별 완료 시각·실제 지급 EXP를 보관한다. 과거 저장 파일에 필드가 없어도 기존 게임 EXP·골드·진행도를 유지한다.

클라우드 계정의 첫 로그인 시각은 계정별 기기 캐시의 `firstLoginAt`에 먼저 보관한다. 건강 정보 저장 동의 후 기존 게임 스냅샷 동기화 경로로 시작 시각과 완료 영수증을 저장하며, 서버에서 복원한 시작 시각을 우선한다. 동의 전의 최초 시각은 해당 계정의 기기 메타데이터로 보관한다. 계정 전환 시 다른 계정의 기간·완료 이력을 물려주지 않는다.

## 검증

- `npm ci` 완료. 실행 중인 해당 작업 트리의 Vite 서버를 잠시 종료해 Windows 네이티브 빌드 모듈 잠금을 해제한 뒤 설치했다. 검사 후 같은 127.0.0.1:5173 주소에서 최신 서버를 다시 실행했다.
- lint·format:check·전체 단위 테스트 314개·프로덕션 build 통과.
- 관련 브라우저 시나리오 19개 통과: 첫 가입 3단계, 두 퀘스트 지급·중복 방지, 기한 만료, 부분 수정으로 보상받지 못함, 기존 프로필 수정과 없음·모름·0, 약 등록 초안, 작은 화면·가로 화면 레이아웃.
- 단위 테스트에서 7일 경계 1ms 전/정각, 다음 날과 복원, 기존 사용자 이관, 계정별 첫 로그인 시각·완료 내역의 재로그인/계정 전환을 검증했다.
- 320·360·384·390·412·430·600px 폭과 892×412 가로 화면, 큰 글자 옵션을 검사했다. 최초 혈압 화면과 첫 주 퀘스트의 스크린샷을 확인했다.
- 클라우드 계정 복원 검증은 모킹한 API와 합성 계정으로 진행했다. 실제 사용자의 가입·건강 기록을 변경하지 않았다.
- 이번 작업은 로컬 구현과 검증이며 모바일 배포 버전은 갱신하지 않았다. 기존 큰 JS 청크·push-notifications import 관련 빌드 경고가 남아 있으나 빌드는 성공한다.
