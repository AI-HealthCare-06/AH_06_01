## 규칙
- 파일명: `<문서명>_6기_1팀(김종민, 김채준, 김태호, 지세진, 최성민)_v<버전>.<확장자>`
- 버전은 파일명 끝 `_v0.1` 처럼 올리고, 이전 버전은 지우지 않고 남긴다(변경 이력 = git log).
- API 스펙·데이터 구조 변경 시 요구사항 정의서 / ERD / API 명세서를 같은 PR에서 함께 수정한다.
- 원시 데이터·개인 단위 행은 docs 에 넣지 않는다(집계값·출처 URL만).
