## 실제 로컬 모델 응답과 한계

`POST http://127.0.0.1:8009/predictions/bp-stage`에 `{"demo_persona":"office-month-v1"}`을 보내 HTTP 200 응답을 확인했다. 원본은 `persona-a-local-model-result.json`, 모델 가중치·임계값 해시는 `model-run-provenance.json`에 있다. 외부 식단 VLM에 사진을 전송하지 않았다.

이 페르소나는 실측 혈압이 있으므로 기존 M1 규칙에서 `data_quality=not_applicable`이다. M2 계약 검사는 `ok`지만 **10개 상태 모두 `not_evaluable`**였다. 필요한 M1 단계·일부 미기재 지표가 없기 때문이다. 문서에 적힌 예상 고혈압 단계나 모델 확률을 임의로 만들지 않았다. 화면의 선택 물 퀘스트는 고정 선택 항목이며 이를 M2 맞춤 처방 결과로 보지 않는다.

서버 어댑터의 회귀 검사 **17개**는 기존 로컬 Python 3.11/scikit-learn 1.9.0 AI 실행 환경에서 통과했다. 현재 체크아웃의 M2 소스는 최상위 `thresholds` 등의 import 경로에 의존하므로, 이 검증에서는 기존에 정리된 로컬 AI 패키지를 사용했다. 임계값 파일의 SHA-256은 현재 체크아웃과 일치한다. 이는 새 체크아웃의 독립 패키징·운영 배포 검증을 뜻하지 않는다.

## 산출물

- SQL 테이블 14개와 물리 FK의 참조 컬럼·기본키를 대조했다. 운영 DB 조회 권한은 없어 체크인된 마이그레이션 기준이다.
- OpenAPI 3.1의 22개 작업, 로컬 참조 110개, 경로 매개변수와 operationId 중복 여부를 검사했다. 모든 HTTP 경로를 운영 서버에 실호출한 검사는 아니다.
- PDF 3개를 모두 페이지 이미지로 렌더링해 표 넘침·제목 분리·한글 표시를 확인했다. ERD 9쪽, API 19쪽, 와이어프레임 8쪽이다. 와이어프레임은 28개 화면·모달 구성이다.
- JSON·CSV의 30개 날짜가 일치하며, 원본 미기재 혈당·맥박·가족력·수면 증상은 모름으로 유지했다.
- 식단 서비스와 모션 캡처 구현의 변경 내역은 없다. 성능 개선은 후보 조사만 수행했다.
