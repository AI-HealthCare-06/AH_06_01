초기 홈·퀘스트·상점 수치는 Figma와 동일하게 2/5 완료·1,280 코인·3,240걸음으로 시작합니다. 이후 사용자 입력에 따라 완료 수와 코인은 바뀝니다. 마이페이지 원본의 1,240 코인은 공통 상태의 1,280 코인으로 통일했고, 보상 화면의 완료 수는 5개 퀘스트를 기준으로 표시합니다. 공룡 선택은 결과·홈 장면·보상·버프·마이페이지에 반영합니다.

## 서버 연결 전에 확정할 사항

- 원본의 점수는 높을수록 좋은 건강 점수로 표시됩니다. 기획서의 위험도 산식과 같은 개념으로 취급하지 않아야 합니다.
- 원본의 32% 위험도, -0.2%p 퀘스트 효과 등은 디자인 예시입니다. 모델 출력·계산 기간·확률 해석·입력 검증 계약을 정한 뒤 실제 데이터로 교체해야 합니다.
- 기획서와 원본의 공룡 능력치 축 수, 기본 코인/EXP, 하루 퀘스트 수가 일부 다릅니다. 현재는 시각 자료의 문구를 유지하고, 실행 가능한 보상은 도메인 모듈에 명시했습니다. 퀘스트 요약의 +60 COIN 배지는 원본 시연 문구이며 실제 누적 코인과 별개입니다.
- 로그인·약관 동의·알림·건강 데이터 수집 동의 등 실제 운영 절차는 아직 구현하지 않았습니다.
- 원본의 밝은 로그아웃 글자와 비활성 기간 탭 글자는 대비가 낮습니다. 요청대로 색을 유지했으며 운영 전 접근성 검토가 필요합니다.
- 상태 표시줄·카메라 점·하단 인디케이터는 데스크톱/노트북 웹 미리보기에서만 표시하며 휴대폰·태블릿·네이티브 환경에서는 제외합니다. 시간과 배터리·연결 상태는 후속 사용자 요청에 따라 현재 기기의 브라우저 정보로 갱신합니다. 카메라 점·하단 인디케이터는 원본을 비교하기 위한 장식입니다. 모바일 웹에서는 CSS 안전 영역 여백을 적용합니다.

## 2026-09-28 추가 브라우저 피드백

- 홈 안내 배너의 문구를 세로 중앙에 정렬하고 검색 아이콘을 확대했습니다. 전투 HUD와 스테이지 배치를 조정했으며 `AdventureScene`에서 돌진·타격·몬스터 반응·숫자 효과를 동기화합니다. 재생/일시정지는 모든 효과를 같은 위치에서 멈추고 재개합니다. 모션 감소 설정에서는 정지 장면을 표시합니다. 전투 연출의 코인/피해 숫자는 게임 잔액이나 체력을 변경하지 않습니다.
- 레이더는 원본 정적 차트 대신 SVG로 1일차(파란 점선)와 오늘(빨간 실선)을 겹쳐 표시합니다. `services/dino-radar-data.ts`에 있는 두 시계열은 0~100 범위의 UI 시연 값이며 실제 측정 기록이 아닙니다. 실제 이력 API 연결 시 두 시계열을 함께 교체해야 합니다.
- 퀘스트 요약 요소를 행·열로 정렬하고 EXP를 각 흰색 행의 우측 중앙, 오른쪽 여백 10px에 배치했습니다.
- 위험도 전후 수치에 각각 `%`와 변화량 `%p`를 표시합니다. 색상은 데이터의 `tone`/`projectedTone`을 사용하며 화살표는 두 색의 그라데이션입니다. 현재 예시의 고혈압은 주의→주의, 당뇨는 낮음→낮음, 고지혈증은 관리 필요→주의로 표시합니다. 이는 데모 표현이며 임상 기준으로 위험군을 계산하는 로직은 없습니다.
- 상점 지갑의 제목·설명·잔액을 재배치하고, 무료 코인 버튼을 카드 우하단으로 옮겼습니다. 상품 영역을 432px로 늘리고 내부 스크롤을 추가했습니다. 분류 탭은 고정되고 상품 사진/카드가 커졌으며 키보드로도 목록을 스크롤할 수 있습니다.

## 실시간 기기 상태 및 탭 높이 통일

- `useDeviceStatus`는 기기의 현지 시간대를 사용해 시간을 표시하며 매초 확인합니다. 창 복귀·탭 가시성 변경 시에도 갱신합니다. `StatusBar`의 시간·카메라 점·연결·배터리 아이콘은 같은 세로 중심을 사용합니다.
- 배터리는 [Battery Status API](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/getBattery)의 잔량·충전 여부와 변경 이벤트를 반영합니다. 브라우저가 API를 제공하지 않거나 접근을 차단하면 잔량을 `—`로 표시합니다. 별도 권한 요청이나 기기 정보 저장은 하지 않습니다.
- 연결 여부는 [navigator.onLine](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/onLine), 연결 종류는 지원 시 [NetworkInformation.type](https://developer.mozilla.org/en-US/docs/Web/API/NetworkInformation/type)을 사용합니다. 연결 아이콘은 브라우저가 판단한 네트워크 상태이며 서버 접근 성공이나 Wi-Fi 신호 세기를 측정하지 않습니다. 미지원 환경에서는 일반 네트워크 아이콘을 표시하며 연결 상태로 앱 기능을 막지 않습니다.
- Home/Quest/Dashboard/Shop은 공통 flex 레이아웃, 콘텐츠 최소 높이 620px, 동일한 메뉴·인디케이터 여백을 사용합니다. 데스크톱 전체 최소 높이는 882px이고 큰 창에서는 화면 높이에 맞춰 늘어납니다. 모바일에서는 OS 상태 표시줄을 중복하지 않고 안전 영역 여백을 유지합니다.

## 퀘스트 진행률과 탭 진입 애니메이션

- 모든 퀘스트 행은 `questProgress`의 상태를 사용해 진행률 바와 퍼센트를 표시합니다. 초기 예시는 복약·식사 100%, 걷기 54%, 물 마시기 0%, 수면 88%이며 완료 처리 후 100%로 갱신됩니다. 새 날짜의 초기화 역시 기존 도메인 상태를 따릅니다.
- 완료 체크는 `PixelCheckbox`의 계단형 SVG 도트 그래픽입니다. 퀘스트 행 좌우 여백은 10px이며 진행률 표시를 위해 행 높이 56px, 목록 높이 322px를 사용합니다. 기존 탭 공통 전체 높이는 유지합니다.
- 메인 탭 진입 시 진행률 바는 왼쪽부터 채워지고, 레이더의 1일차/오늘 시리즈는 중심에서 펼쳐집니다. 주요 수치(진행률, 스테이지, 점수, 위험도, 코인)는 약 700ms 동안 올라갑니다. 날짜·기기 상태·상품 가격은 이 연출의 대상이 아닙니다.
- `AnimatedNumber`는 실제 숫자를 접근 가능한 DOM에 유지하고 별도의 장식 표시만 갱신합니다. 애니메이션은 게임 상태나 건강 데이터를 수정하지 않으며, 재방문 시 다시 시작하고 같은 화면에서 보상이 증가하면 표시 중인 숫자에서 이어집니다. 탭을 떠날 때 프레임 예약과 이벤트 구독을 해제합니다.
- `prefers-reduced-motion`을 따르며 설정이 실행 중 바뀌어도 움직임을 멈추고 최종 값을 즉시 표시합니다. 그래프·바 애니메이션도 해당 설정에서는 실행하지 않습니다.

## 확인 방법

390 × 844에서 원본과 브라우저 캡처를 비교하고 이미지 슬롯·크기·본문 위치를 조정했습니다. 320/390/430/1440px 폭에서 메뉴 이동을 확인합니다. 실제 Android/iOS 기기·에뮬레이터 검증과 픽셀 완전 일치 판정은 수행하지 않았습니다. 브라우저 글꼴 렌더링에 따른 차이는 남을 수 있습니다.
