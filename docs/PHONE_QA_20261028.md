## 실제 입력·레이아웃 확인

운영 계정의 건강 기록을 변경하지 않도록 별도 QA 패키지의 합성 데모로 입력 테스트했다. 숫자/한국어 키보드 상태와 실제 스크린샷을 확인했다.

- 서베이: 10단계 이동, 시각 길게 누르기(58분에서 04분까지 반복·순환·해제 후 정지), 0·10 슬라이더와 별도 모름, 제출·재실행 후 저장 유지.
- 수면: 23:00→06:30을 7.5시간으로 반영. 기존 6.2시간 보너스 418 EXP에서 506 EXP로 88 EXP 추가. 동일 기록 재제출 시 EXP는 8,579로 유지.
- 약/영양제: 모달에서 등록→재실행→성분 수정→취소→삭제. 영양제 가로 라디오, 성분 입력과 한국어 키보드·스크롤 동작 확인. 알림 권한을 임의로 변경하거나 실제 복약 알림을 발송하지 않았다.
- 대시보드: 우측 세부 수치, 수면 소수점 한 자리, 66px 달력, 기간 필터, 혈압·맥박·혈당 그래프, M1·M2 응답과 Sub Quest를 확인. 가로 넘침 없음(411 CSS px).
- 모델은 고정 합성 페르소나 API를 실제 호출한다. 혈압약 복용 대상의 M1 대상 제외 계약과 M2 수면 확인 항목 응답을 보존했다. 로컬 편집값이 인증된 사용자 모델 입력으로 전달됐다고 주장하지 않는다. 건강 점수 82와 점수 변화는 기존 데모 값이다.

## 발견한 문제와 수정

기존 BGM은 짧은 단선율 반복과 작은 게인이었으며 사용자가 음질·음량 개선을 요청했다. 맵별 8마디 원곡에 멜로디·화음·베이스·리듬을 구성하고 부드러운 음량 엔벨로프와 오디오 시계 기반 예약을 적용했다. 앱 내부 BGM과 SFX 게인을 높였고, 사용자가 실제 스피커에서 개선된 음악·음량을 확인했다. 시스템 음량 설정은 테스트가 변경하지 않았다.

Android 홈 전환 후 네이티브 앱은 비활성인데 WebView의 document.visibilityState는 visible로 남는 현상을 재현했다. 기존 visibilitychange만으로는 소리가 계속 날 수 있었다. Capacitor App의 실제 앱 활성 이벤트와 초기 활성 상태를 함께 적용해 백그라운드에서 모든 음원·스케줄러를 정지하고 복귀 시 기존 오디오 컨텍스트를 재개하도록 수정했다.

실기기에서 BGM 단독·SFX 단독, 둘 다 OFF, 설정 저장, 일시정지, 백그라운드 완전 무음, 추가 페이지 터치 없이 복귀 재생, 다른 탭 이동 시 컨텍스트 종료를 확인했다. Android 전환 애니메이션이 끝난 실제 비활성 이벤트를 기준으로 검사했다. ALPINE DAY·FOREST RUINS·ISLAND COAST를 직접 선택해 각 멜로디가 바뀌는 것도 확인했다. 앱 자체 WebAudio 그래프만 기록했으며 마이크·다른 앱 소리를 녹음하지 않았다.
