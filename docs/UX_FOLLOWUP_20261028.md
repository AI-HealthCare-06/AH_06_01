# 2026-10-28 서베이·복용 항목·대시보드·게임 후속 수정

브랜치: `feature/pixel-adventure-device-quests`. 이번 수정은 로컬 구현과 검증이다. 공개 웹, Supabase 함수·자동 업데이트 채널, 운영 APK는 게시하지 않았다. 기존 네이티브 1.5.0(10) / 공개 OTA 1.5.6을 변경하지 않는다.

## 검증

- `npm ci`로 lockfile 설치.
- 전체 Vitest **304/304**, `npx vitest run --maxWorkers=2`. 초기 무제한 동시 실행에서 발생한 모듈 초기화 시간 초과는 동시 실행 수를 줄인 전체 실행에서 해소됐다.
- Playwright 최종 묶음 **23/23**: ux-followup, daily-survey, profile-avatars, combat-settings. ux-review 기본 흐름 5개와 demo-survey-week 1개도 통과했다. cloud 동기화 UI의 인증 전용 시나리오는 기본 실행에서 제외됐으며 전체 E2E를 모두 실행한 것은 아니다.
- 프런트엔드 lint / format:check / 타입 검사 / 프로덕션 빌드 통과. 기존 번들 크기 경고는 남아 있다.
- OTA 게시·공지 Deno **14/14**, notify 재시도 함수 타입 검사 통과. 실제 Supabase 쓰기·푸시 발송 없이 mock으로 검증했다.
- AWS collector 타입 검사와 기기 등록·인증 회귀 **3/3**. 본문이 소유자를 위조하지 못하며 네이티브 버전을 저장하는지 확인했다.
- Android debug APK 빌드 성공. Gradle init과 별도 debug asset/manifest/config를 사용한 `com.rexrun.demo.uxqa` 패키지만 설치했다. 운영 앱 소스 설정·개인 건강 권한·계정 데이터·시스템 글자 크기는 변경하지 않았다.
- 연결된 **Galaxy S25+ SM-S936N**에서 기기 배율 0.8의 기본 화면, 서베이 슬라이더/모름, 영양제 성분 모달, 모의 새 버전 NEW 강조를 확인했다. 퀘스트→Back→홈→Back 토스트→Back 종료를 실제 Android 키 이벤트로 검증했다.
- 기기 WebView 자동 캡처가 일부 Canvas 레이어를 생략하므로 게임 캐릭터와 골드 도착은 별도 실제 디스플레이 캡처로도 확인했다. 무음 기기에서 청취 품질을 평가한 것은 아니다.

## 배포 시 주의

기기 글자 배율용 MainActivity 변경에는 새 네이티브 APK와 호환 채널이 필요하다. 서버 푸시는 `rexrun-ota-publish`, `rexrun-notify`, collector 변경을 배포한 뒤 수신 허용 기기에서 실제 수신을 확인해야 한다. 이번 작업에서는 운영 배포·외부 발송을 실행하지 않았다. 생성 빌드·브라우저/기기 캡처·비밀 설정은 Git에 추가하지 않는다.

## 실제 배포 결과

2026-10-28 후속 배포 요청에 따라 새 APK **1.5.1(11)**과 OTA **1.5.8**을 공개 게시했다. 앞의 미배포 표기는 로컬 구현 완료 시점의 기록이다. 기기 기본 배율 코드는 새 APK에 포함되며 기존 1.5.0 APK도 호환 웹 수정사항을 OTA로 받는다. 서버·FCM 설정·공개 웹 검증을 완료했다. 이번 배포 시점에는 휴대폰 USB 연결이 없어 새 APK 덮어설치나 실제 OTA 수신을 확인하지 않았으며 앞의 별도 QA 앱 검사와 구분한다. [설치·전체 검증](MOBILE_RELEASE_20261028.md).

## 운영 APK 기기 후속 확인

2026-10-28 연결된 Galaxy S25+에서 후속 확인을 완료했다. 기존 APK 1.5.0의 OTA 1.5.8 수신, 같은 서명의 APK 1.5.1(11) 덮어설치, 재실행 후 새 채널 OTA 1.5.8 적용을 확인했다. 앱 UID·최초 설치 시각·로그인된 프로필이 유지됐으며 사용자 기기 설정은 변경하지 않았다. 실제 배포 앱에서 다른 화면의 Back→홈, 홈의 첫 Back→토스트, 두 번째 Back→종료를 통과했다. 확인 후 앱을 다시 홈 화면으로 열어 두었다.
