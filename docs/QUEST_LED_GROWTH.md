# 퀘스트 중심 성장 및 M1·M2 연결

작업 브랜치: feature/pixel-adventure-device-quests

## 성장 규칙

|퀘스트|첫 기본 EXP|첫 Gold|하루 인증 상한|
|---|---:|---:|---:|
|약 복용하기|80|150|1|
|건강한 식사하기|120|200|3|
|6,000걸음 걷기|180|300|1|
|물 마시기 실천|100|150|2|
|수면 7시간|140|250|1|

첫 완료 합계 620 기본 EXP / 1,050 Gold. 5개 모두 완료하면 200 Gold를 한 번 추가한다. 기존 레벨 보정(1 / 1.5 / 2.25 / 3.375배, 내림)과 레벨업 Gold는 유지한다. 식사·물의 허용된 추가 인증에는 첫 EXP의 10%를 지급한다. 자동전투 EXP는 하루 기본 40에 같은 레벨 보정을 적용한 한도까지 지급하며, 리로드로 충전되지 않고 날짜 변경 시 초기화한다. 한도 이후 처치 팝업도 EXP를 표시하지 않는다. 기존 저장 EXP·Gold는 소급 변경하지 않는다.

복약 공격력 +10%는 하루 한 번, 식사 피해 감소 +20%는 최대 3회, 물 공격 속도 +40%는 120분 간격 최대 2회. 걷기 완료는 6,000보이며 치명타 보너스는 8,000보부터 2,000보당 20%다. 수면 Gold 버프는 수면 퀘스트 완료 후 7시간 +10%, 8시간 +20%다. 짧은 수면도 기록하지만 완료 보상은 주지 않는다. 하루가 바뀌면 일일 버프를 초기화한다. 물의 실제 카메라 동작 인증을 8잔 섭취로 해석하지 않는다.

## 모델과 추천

M2 원본: feature/ai-htn-risk @ 0da150ed95c33cad0af2b964e9b9584b043cd0dd. 임상 규칙·임계값은 변경하지 않고 Python 패키지 이름 충돌만 해소했다. 원본 테스트 210개 통과. M1-S 고정 모델의 적용 대상 제외를 그대로 전달한다. 혈압약 복용자의 M2 연결은 원본 M2의 medication contract에 따른 htn 입력이며 M1 예측 확률로 표시하지 않는다. 적용 가능한 M1 단계가 없으면 unavailable로 전달한다.

Sub Quest는 전날 저장된 퀘스트 완료 ID, 걸음·수면, M2 상태에 따른 투명한 규칙 기반 상위 3개 추천이다. 미완료 복약 100, 짧은 수면 80(야간 확인 항목이면 95), 낮은 걸음 70, 식사 기록 없음 60, 물 기록 없음 50 순이다. 없는 기록을 미완료로 추정하지 않으며 기본 인증과 보상을 재사용한다. 약 추가 복용·용량 변경을 권하지 않는다.

## 데모 분리

고혈압·당뇨 합성 페르소나는 별도 localStorage 접두사로 저장하며 실제 계정 동기화·건강 데이터 읽기·복약 알림과 분리한다. 로그인 화면의 데모 체험으로 진입하고 종료 시 원래 계정 저장을 유지한다. 고혈압약 08/13/20시, 인슐린 08시를 합성 일정으로 제공한다. 7일 수면 5.4~7시간, 혈압 147~156/93~98, 공복혈당 148~162, 맥박 78~84는 화면 검증용 합성 값이며 환자 집단 평균이 아니다.

공개 모델 API는 정확히 고정된 demo_persona 입력만 인증 없이 받고 사용자 프로필은 읽지 않는다. 그 외 분석은 기존 JWT·동의·RLS 경로를 사용한다. 응답 없음/실패 시 기다림/재시도를 표시하며 점수나 확률을 만들어내지 않는다. 계정·동의·건강 입력이 바뀌면 기존 결과를 즉시 숨긴다.

## 검증과 배포

동일 엔진·5개 난수 시드의 1시간 비교에서 이전 자동전투 단독은 레벨 7, 변경 후 단독은 레벨 1/40 EXP였다. 변경 후 첫 퀘스트 5개 완료는 레벨 5와 레벨 보정된 전투 한도 60 EXP였다. 실제 기기의 장기 성장 속도는 별도로 관찰해야 한다. 320/390/430px 대시보드·퀘스트·캐릭터·복약 화면 가로 넘침이 없었다.

OTA 대상은 native 1.4.0, android/galaxy-test 채널이다. 새 웹 버전 1.4.4 발행 전 전체 파일 해시·서명과 기존 네이티브 호환 지문을 확인한다. 공개 설치는 기존 서명 APK 1.4.0(9)을 사용하고 첫 실행에 OTA를 받는다. 2026-10-22에 모델 API 배포와 공개 데모·두 합성 계정의 실제 M1·M2 응답을 검증했다. 저장 이력은 기존 RLS가 적용된 game_saves에서 호출자의 JWT로 조회한다. OTA 1.4.4를 발행하고 308개 경로/278개 고유 파일 전체의 서명·해시를 확인했다. [공개 설치 페이지](https://d4vy5vn0lhbgi.cloudfront.net/install/index.html), APK 전체 다운로드 해시와 QR을 비로그인 상태로 검증했다. 공개 웹의 320/390/430px 화면에서 실제 모델 호출·추천 3개·데모 종료가 정상이고 가로 넘침과 페이지 오류가 없었다. 2026-10-22 사용자가 기존 설치 앱의 최신 업데이트 확인을 완료했다고 알려왔다. 이번 확인에서 신규 설치·카메라·건강 센서 동작은 별도로 확인하지 않았다.

로컬 검증: 프런트엔드 lint/format/빌드, 단위 240개, M2 원본 210개, API 단위 15개, 로그인·계정 결과 격리·데모 진입 10개. 브라우저 전체 검사를 실행해 이전 화면 구조·보상을 전제로 한 기대치를 수정했으며 실패 항목과 남은 spec을 재실행했다. 일괄 실행에서 한 차례 발생한 Stego 이미지 준비 타이밍 실패는 단독 재실행으로 통과했다.
