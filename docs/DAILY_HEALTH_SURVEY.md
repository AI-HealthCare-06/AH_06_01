# 일일 건강 서베이와 메인 퀘스트

2026-10-27 · `feature/pixel-adventure-device-quests`.

현재 OTA 1.5.6의 메인 퀘스트는 건강 서베이·약 / 영양제 복용·식사·걷기 4개다. 수면은 서베이에 통합하고 기록된 시간에 따라 추가 EXP를 지급한다. 물 마시기는 항상 접근 가능한 선택 Sub Quest로 이동했으며 메인 진행률·모두 완료 보너스·새 주간 달성 조건에서 제외한다. 기존 물 동작 인증·120분 간격·하루 2회 버프는 유지한다. 과거 완료일과 기존 잔액을 재계산하거나 보상을 소급 지급하지 않는다.

`/daily-survey`에서 오늘의 질문에 답한다. 측정값의 정상 여부를 보상 조건으로 삼지 않으며 미측정·모름도 명시적 응답으로 보관한다. 혈압의 수축기·이완기는 함께 입력하며, 잘못된 쌍이나 미래·다른 날짜의 제출은 거부한다. 같은 날 아침 기록에 저녁 기록을 추가할 수 있고, 수정을 반복해도 EXP·골드 보상은 하루 한 번이다. 서베이는 전투 버프를 추가하지 않는다.

| 입력 | 수집 방식 | 분석 사용 |
| --- | --- | --- |
| 아침·저녁 혈압 | 측정한 시간대만, 미측정 선택 가능 | 날짜별 혈압 추이. 실측 혈압이 있으면 기존 M1-S 추정 제외 원칙 유지 |
| 안정 시 맥박 | 일일 측정 또는 미측정 | M1 resting_hr, M2 pulse_hr |
| 어젯밤 수면 시간 | 취침·기상 시각, 수면 없음 또는 모름 | M1 sleep_hours, M2 sleep_snoring, 대시보드 |
| 공복 혈당 | 측정한 경우 선택 입력 | M1 fasting_glucose, M2 fpg, 날짜별 추이 |
| 중강도 활동 시간 | 일간 분 수, 선택 입력 | 연속 7일이 모두 있을 때 주간 분으로 합산. 불완전한 7일 기록을 0으로 채우지 않음 |
| 좌식 시간 | 일간 시간, 선택 입력 | M2 sedentary_hours |
| 코골이·주간졸림·야뇨 | 코골이·졸림 0~10 또는 모름, 야뇨 예·아니요·모름 | M2 수면·증상 입력. 점수 원본을 보관하고 현재 불리언 계약에는 증상 유무를 전달. 모름은 결측 |

나이·성별·키·가족력·진단·치료 상태 등 가입 정보는 매일 다시 받지 않는다. HbA1c·지질·신장 검사와 진료실·ABPM 검사는 일일 서베이에 넣지 않는다. 원본 전달 문서 `docs/toDev/혈압_임상조사_데이터·질환·저혈압·입력정보·병원지침_v1.2.xlsx`의 앱 입력 구분과 `ai/m2_state/feature_contract.yaml`의 타입·단위·결측 계약을 참고했다. 원본 로컬 문서는 별도로 보존하며 자동 게시하지 않는다. 입력 범위는 전송 검증이며 개인별 목표나 정상 범위가 아니다.

## 저장과 분석

- `game.dailySurveys[YYYY-MM-DD]`에 응답을 보관하고, `healthHistory`에 같은 날짜의 혈압·맥박·공복 혈당·수면을 반영한다. 저녁 혈압이 있으면 그 날짜의 대표 표시값으로 사용하며 아침 원본도 남긴다.
- 서버 전송에 동의하지 않아도 해당 계정의 기기 캐시에 보관한다. 다른 계정과 분리하고 명시적 게임 초기화 때 캐시도 제거한다. 정상 저장이 실패하면 서베이 보상을 지급하지 않는다.
- 저장 동의를 켜면 기존 계정별 `game_saves.snapshot` 동기화로 전송한다. RLS·건강 정보 저장 동의·서버의 사용자 검증을 유지한다. 확인된 스냅샷 키에 일일 응답을 포함해 저장 확인 후 모델 응답을 갱신한다. 전투 틱은 모델 호출을 추가로 유발하지 않는다.
- M1·M2는 해당 날짜의 서베이를 읽고 지원하는 항목에만 연결한다. 실측 혈압 한 쌍을 7일 평균이나 M1 단계로 둔갑시키지 않는다. M2의 M1 저녁 단계 등 미연결 분기는 계속 `not_evaluable`이다.
- 데모 모드의 모델 호출은 기존 고정 합성 입력을 유지한다. 실제 계정의 일일 기록으로 분석하려면 건강 정보 저장 동의가 필요하다.
- 서버 카탈로그 마이그레이션은 `daily_health_survey_quest`이다. 사용자 테이블과 RLS는 바꾸지 않고 퀘스트 그룹 메타데이터와 서베이 정의만 추가한다.

## 검증

전체 앱 단위 285개, 관련 모바일 브라우저 14개, 모델 어댑터 18개와 정적 검사·빌드를 통과했다. 합성 계정으로 실제 서버 저장·모델 응답의 일일 서베이 날짜·실측 M1 제외를 확인하고 테스트 스냅샷을 복원했다. 320/390/430px 배치를 확인했다. 모델 학습·임계값·모델 바이너리는 변경하지 않았으며 임상 정확도 평가가 아니다.

## 배포 완료 · 2026-10-27

AWS 모델 입력 어댑터, Supabase 카탈로그 마이그레이션 `20261027024824`, 공개 웹 및 galaxy-test/native 1.5.0의 서명 OTA **1.5.4**를 게시했다. 기존 native 1.5.0(10) 앱은 재설치 없이 마이페이지 → 앱 업데이트 → 업데이트 확인으로 받는다. 다른 네이티브 채널 1.1.0/1.2.0/1.2.1/1.3.0/1.4.0은 이전 manifest와 바이트가 동일하다.

원격 308개 경로/278개 고유 파일, 141,419,155바이트 전체의 서명·SHA-256을 확인했다. 실제 공개 웹의 합성 테스트 계정으로 메인/서브 분리, 서버 동의 전 기기 기록의 새로고침 유지, 혈압 요약, 서버 스냅샷과 정규화된 서베이 완료 기록, M1·M2 응답의 일일 서베이 날짜 표시를 확인했다. 테스트 계정의 원래 게임 스냅샷은 복원했다. 개인 계정 건강 기록은 조회하지 않았다. 마지막 배치 변경 후 일일 서베이 브라우저 테스트 4개도 다시 통과했다.

카탈로그 RLS와 authenticated 읽기 정책은 유지했다. DB advisor 오류는 없으며 기존 `auth_leaked_password_protection` 경고는 이번 변경 범위 밖으로 유지했다. 원격 이력에 기존 동의 마이그레이션의 타임스탬프가 로컬 파일과 달라 일반 db push가 중단되어, 이번 SQL 파일만 트랜잭션으로 적용하고 해당 버전 하나를 공식 CLI migration repair로 기록했다. 기존 이력은 수정하지 않았다.

[공개 일일 서베이](https://d4vy5vn0lhbgi.cloudfront.net/daily-survey). 실제 단말에서 업데이트 적용과 입력 장치 사용감 확인은 별도다. 새 웹 버전은 **1.5.5 이상**을 사용한다.

## 항목별 모달 변경 · 2026-10-27 · OTA 1.5.5

서베이는 홈·퀘스트·대시보드 위에 네이티브 HTML dialog로 열린다. 퀘스트에서는 기존 설명 모달의 ‘서베이 작성’으로 전환하며 두 모달을 중첩하지 않는다. 직접 `/daily-survey` 주소로 들어가면 퀘스트 목록 위에서 열린다. 닫기·Escape·브라우저 뒤로 이동 시 원래 화면으로 복귀하고 대시보드 필터와 스크롤, 진입 버튼의 포커스를 유지한다.

혈압 → 안정 시 맥박 → 어젯밤 수면 → 공복 혈당 → 활동 시간 → 좌식 시간 → 코골이 → 낮의 졸림 → 밤중 화장실 → 입력 내용 확인 순서다. 한 번에 한 항목만 표시하고, 이전·다음과 진행률을 제공한다. 선택 항목의 건너뛰기는 값을 결측으로 유지하며, 실제 0을 결측으로 바꾸지 않는다. 확인 화면에서 항목을 골라 수정할 수도 있다. 단계 이동은 서버 저장·완료 보상을 발생시키지 않고 최종 제출 때만 기존 `recordSurvey` 경로를 호출한다. 제출 전 모달을 닫으면 미제출 초안은 저장하지 않는다. 같은 날의 이미 제출한 기록은 다시 열어 수정할 수 있다.

필드 검증은 기존 스키마를 사용하되 오류 경로를 명시하고 각 단계의 응답만 검사한다. 최종 제출 때는 전체 항목과 당일 날짜를 다시 검증한다. 데이터 형식·저장 동의·보상·대시보드·모델 어댑터 및 Supabase 스키마는 바꾸지 않았다. UI 변경만으로 기존 native 1.5.0(10)과 호환되며 APK 재설치 없이 웹 자동 업데이트를 받는다.

검증: 전체 단위 테스트 285개, 관련 브라우저 테스트 9개, 마지막 수정 후 서베이 6개 재검증, lint·format·타입/프로덕션 빌드. 320/390/430px 및 짧은 화면에서 모달/고정 하단 버튼을 확인했다. 공개 웹 데모로 항목 전환·이전 값 유지·확인/저장·닫기 복귀를 확인했고, OTA의 모든 파일 서명·해시를 검증했다. 실제 모바일 WebView의 키보드 및 업데이트 적용 확인은 단말 테스트가 필요하다. 다음 웹 버전은 1.5.6 이상을 사용한다.

## 입력·보상 수정 · 2026-10-27 · OTA 1.5.6

> 최신 화면·서베이 수정 (2026-10-27): native **1.5.0(10)** 유지 / 서명 OTA **1.5.6**. 취침·기상 시간, 0~10 응답, 수면 EXP 보너스, 4개 메인 퀘스트, 약/영양제 명칭, 완료 퀘스트 알림, 상점 가격과 간단한 설정 행을 반영했다. 연결 Galaxy S25+에서 재설치 없는 적용 및 두 번 Back 종료를 확인했다. 다음 웹 버전은 **1.5.7 이상**이다. [변경 내용·검증·가격 출처](UX_REVIEW_20261027.md).

서베이 설명은 툴팁, 선택지는 라디오로 바꾸고 수면을 취침·기상 시각으로 받는다. 자정 경과를 처리하며 같은 시각은 0/24시간이 모호하므로 거부한다. 실제 수면 0시간은 별도 선택으로 저장한다. 기존 시간형 기록은 그대로 읽고 취침 시각을 임의 생성하지 않는다. 수면 보너스는 시간당 기본 20 EXP, 기본 160 EXP 상한에 기존 레벨 배율을 적용한다. 당일 이전 최대 보상보다 증가한 차액만 지급하고, 과거 수면 퀘스트 보상과 중복 지급하지 않는다. 원본 점수·시간은 서버 동의 범위에서 일일 스냅샷에 보관한다. 모델 학습과 임계값은 바꾸지 않았다.

이번 버전 검증: 단위 292개, 관련 브라우저 31개, 공개 합성 계정의 실제 저장·모델 날짜 확인과 스냅샷 복원, 원격 전체 OTA 서명·해시 확인, 연결 Galaxy S25+의 업데이트·실제 Back 동작·설문 배치 점검. 실제 계정의 설문/복용 기록은 제출하지 않았다.
