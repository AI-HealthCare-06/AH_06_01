# 성별 분리 역체인(dbp→sbp) 검증 — 그동안의 방법 적용 (validate_dbp_20261029)

- 구조 고정: 성별 분리, 전 열 → dbp, 전 열 + dbp(학습 실제·추론 예측) → sbp. 3단계 라벨: sbp (122.0, 140.0) 또는 dbp (80.0, 90.0). 5겹 층화 CV, 접힘마다 전처리·추가 데이터·모델 재학습.
- 기준 = 문헌 기준값 중심 입력 + LightGBM 역체인(train_sex_chain.py 와 같은 설정). Δ = 후보 − 기준(접힘별 짝지은 차이의 평균), CI95 = 1.96·sd/√k. |Δ| 가 CI 보다 크면 '잡음 밖'.
- point_acc: 점추정(예측 sbp 로 단계) 정확도, dist_acc: 분포 argmax 정확도, auroc_ge140: htn 확률의 AUROC, recall_htn: 점추정 htn 재현율, exp_upper: 평균 max P(기대 상한), train_*: 학습 행 지표(과학습 점검).
- '참고(배포 불가)' 는 실제 dbp 를 넣거나 입력을 줄인 비교용이며 제품에 쓸 수 없다. 분류 전용 방법(소프트 라벨·two_axis·계층 분류·자기학습·LDA/QDA/NB)과 행 검증 변형은 넣지 않았다(머리말 참조).
