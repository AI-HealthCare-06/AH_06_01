# 참고 수치표 (문헌 근거, 모델 설계 판단의 출처)

## M1 설계에서 이 표가 쓰인 곳

- 혈압 단계 경계 → `thresholds.py` SBP_*/DBP_* (대한고혈압학회)
- 당뇨 플래그 산출 → FASTING_GLUCOSE_DM, HBA1C_DM (대한당뇨병학회 2021)
- 이유 코드 bmi_high → BMI_HIGH 23 (WHO 2004 아시아 행동점, 사용자 결정 2026-10-20); waist_high → WAIST_HIGH_CM (대한비만학회 2022)
- alcohol_per_day 경계 → ALCOHOL_DRINKS_PER_DAY_HIGH (Roerecke 2017, ≤2잔/일 효과 없음)
- 단조 방향 → `feature_contract.yaml` monotone (허리둘레 Rhee 2018, 체중 Neter 2003, 운동 Cornelissen 2013, 나트륨 Filippini 2021, 수면 Hosseini 2024, 심박수 Shi 2018)
- 흡연 부호 제약 없음·포함/제외 비교 → Lee 2001 vs Kunutsor 2025 상충
- mmHg 점 추정 미출력 → 혈압 없는 검증 점수 부재(Parikh 2008, Lim 2016)
