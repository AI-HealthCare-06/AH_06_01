## 2. 용어를 먼저 풀어 두기

- **혈압 단계(stage)**: 수축기(sbp)·이완기(dbp)로 나눈 4단계. normal(sbp<120 이고 dbp<80), elevated(sbp 120~129 이고 dbp<80), prehtn(sbp 130~139 또는 dbp 80~89), htn(sbp≥140 또는 dbp≥90). 학습 데이터에서는 실제 측정 혈압으로 이 단계를 만들어 "정답"으로 씁니다.
- **정확도(정답률)**: 모델이 찍은 단계가 정답 단계와 같은 비율. 4단계 중 하나를 맞혀야 하므로 어렵습니다.
- **기준선**: 아무 정보 없이 가장 흔한 단계(normal)만 찍었을 때의 정확도(약 49~51%). 모델은 이보다 얼마나 높은지로 평가합니다.
- **AUROC**: "고혈압(≥140/90)인 사람에게 더 높은 위험 점수를 주는가"를 0.5(무작위)~1.0(완벽)으로 잰 값. 정확도와 달리 "순위를 잘 매기는가"를 봅니다. 0.73이면 두 사람을 무작위로 뽑았을 때 73%는 고혈압인 쪽에 더 높은 점수를 준다는 뜻입니다.
- **시간 분할**: 검진 연도 순으로 앞 70%는 학습, 그 다음 15%는 검증(설정 고르기), 마지막 15%는 테스트(성적 재기). 미래 데이터에 대한 성적을 흉내 냅니다.
- **5겹 교차검증**: 데이터를 5조각으로 나눠 "4조각으로 학습, 1조각으로 테스트"를 5번 반복해 평균을 냅니다. 한 번의 분할 운에 좌우되지 않도록 하는 방법입니다. 두 방법의 차이가 "잡음 범위"라는 말은, 5번 반복한 차이의 흔들림(신뢰구간)보다 차이가 작다는 뜻입니다.
- **대치(결측 채우기)**: 비어 있는 값을 규칙으로 채우는 것. 모델은 빈 칸을 받을 수 없어서 필요합니다.
- **표준화**: 변수마다 단위가 달라서(나이는 세, 활동은 분) 평균을 빼고 표준편차로 나눠 같은 척도로 맞추는 것. 결과에는 영향이 없고 계수를 읽기 쉽게 하는 용도입니다.
- **LightGBM**: 결정 트리를 많이 쌓아 예측하는 방식. 변수 간의 복잡한 관계를 스스로 찾습니다.
- **체인 모델**: 1단계에서 sbp를 예측하고, 2단계에서 그 sbp를 포함해 dbp를 예측한 뒤 단계를 정하는 구조.

## 3. 데이터

### 3-1. 학습 파일 (train/)

- 46,691행 × 22열. 한 행이 한 사람의 한 검진. 연도 2013~2022(연도별 4,175~5,041행), 여성 56%, 연령 19~80(80은 상한 코딩).
- 입력 후보 17열: age, sex, bmi, waist_cm, alcohol_week(잔/주), alcohol_per_day(0/1), binge(폭음 0/1), activity_minutes_week(분/주), activity_low_flag, family_htn, sodium_risk_score, sleep_short_flag, diabetes_flag, fasting_glucose, resting_hr, education_years, missing_count.
- 정답 열: sbp, dbp(측정 혈압), hypertension(sbp≥140 또는 dbp≥90과 100% 일치하는 파생값).
- 식별·분할용: person_id(전부 고유), exam_year.
- 없는 것: 복약 여부(그래서 전원 비복약으로 가정하고 단계를 만듦), 흡연, 스트레스, 수면 시간 원값(6시간 미만 여부만 있음), 검사 수치.
- 결측: 나트륨 6,279, 가족력 3,378, 활동 3,348, 교육 3,114, 공복혈당 2,245, 수면 2,112, 음주 1,210, 당뇨 320, BMI 295, 허리 264, 심박수 20.
- 단계 분포(정답): normal 49% / elevated 11% / prehtn 24% / htn 15%.

### 3-2. 테스트 파일 (test/)

- 11,673행, 같은 열 구조에 sbp·dbp·hypertension만 비어 있음. 모델이 단계를 채우면 사용자가 정답과 비교해 채점.

### 3-3. 데이터에서 본 주요 사실

- 혈압과 가장 함께 움직이는 변수는 **나이**(상관 0.31), 그다음 허리둘레(0.30), 공복혈당(0.26), BMI(0.25). 음주·운동·수면·나트륨은 0.0~0.05로 거의 무관.
- **sbp와 dbp는 나이에 따라 반대로 움직임**: sbp는 계속 오르지만 dbp는 50대에 정점(78) 뒤 70대에는 20대 수준(71)으로 내려감. 70대 고혈압의 87%는 "수축기만 높은" 유형. 그래서 elevated(sbp 120~129이면서 dbp<80) 단계는 고령자가 많음(중앙 연령 65세).
- 같은 입력값을 가진 사람들의 단계가 실제로 섞여 있음. 예: 60세 이상이면서 생활 변수가 전부 정상인 집단도 단계 분포가 38/17/24/21%. 이것이 정확도가 오르지 않는 근본 원인.

## 4. 진행 경과 (날짜순)

### 10/19 — 명세 확정, 뼈대 구현, 첫 학습

- 명세: 임계값은 thresholds.py 한 곳, 입력 정의는 feature_contract.yaml 한 곳, 혈압값은 입력 금지, 범위 밖 값은 거부, 진단 표현 금지, 데이터 파일은 커밋 금지.
- 후보 모델 3종 구현: 순서형 로지스틱(ordinal), 중첩 이진(nested), 단조 LightGBM(lgbm).
- 첫 데이터 투입 때 열 이름이 명세와 달라 실패 → 사용자가 열 이름을 맞춘 파일 재투입.
- 첫 학습 결과: 세 모델 모두 AUROC 0.72, 정확도 0.52. 명세 예시 합격선(AUROC 0.80)에 못 미쳐 **합격선을 0.70으로 확정**(사용자).
- 단건 추론이 30 ms로 느려서 pandas를 거치지 않는 고속 경로를 만들어 p95 1~2 ms로 단축. 배치 경로와 같은 값을 내는지 학습 때마다 자동 검증.

### 10/20 — 결정 규칙 하나씩 검토

- **risk_level**: 근거 없는 3등급(0.20/0.50 경계)을 폐기하고 4단계와 동일하게 통일.
- **이유 코드**(앱에 보여 줄 위험 요인): 조건마다 한국·아시아 문헌과 고IF 학술지를 조사. 나트륨은 문헌이 서로 충돌하고 데이터 상관 0이라 제거, BMI 경계는 25 → 23(WHO 아시아 기준), 나이·음주 경계는 문헌이 없어 데이터(Youden 지수)로 정함(남 39/여 50세, 남 1.25/여 1.75잔/일 또는 폭음).
- **학습 행**: 결측을 채운 행은 학습에서 빼고 완전한 행만 학습(성능 변화 없음).
- **단계 판정 규칙**: 확률이 가장 큰 단계를 고르면(argmax) elevated는 한 번도 나오지 않음. 누적 확률 임계값 규칙을 추가했지만 정확도는 같음(0.51~0.52). 정확도의 한계는 규칙이 아니라 정보량 때문임을 확인.
- 변수별 기여도: 연령이 33~41%, 성별까지 합치면 절반 이상.

### 10/21 — 정답률 개선 시도 1, 저장소 반영, 문서

- 사용자 제안(나이·BMI 가중치 상향, 생활 변수 정상이면 감점)을 세 가지 방식으로 실험 → 정확도 변화 없음, AUROC는 하락.
- 코드를 팀 저장소 ai/m1_stage에 커밋·PR. 작동 방식 문서와 API 명세 초안 작성.

### 10/22 — Word 문서

- 작동 설명서와 결정 규칙 검토 정리를 Word로 작성.

### 10/23 — 멘토링 후 재시작: 데이터 분석

- 변수별 모델 기여도, 단계별 히스토그램, 변수 간 상관 행렬을 엑셀·그림으로 정리(reports/analysis_*).
- 나이대별 변수 요약과 "각 변수가 혈압을 얼마나 움직이는가"(나이·성별 보정 기울기) 분석. BMI 1당 sbp +0.85, 허리 5 cm당 +1.46, 음주 7잔/주당 +1.17, 운동은 거의 0(+0.04), 심박수 10 bpm당 dbp +0.96, 수면 부족은 보정 후 +0.4.
- sbp·dbp가 나이에 따라 반대로 움직이는 패턴 발견(3-3 참고).
- 사용자 제안 "sbp를 먼저 예측하고 그 값으로 dbp를 예측하는 체인"을 점검: 예측 sbp는 입력의 함수라 dbp에 새 정보를 주지 못함(R² 0.114로 동일). 점 추정을 경계로 자르면 htn 재현율 0.002. 확률 분포로 내면 AUROC 0.708. → 보류.
- 새 방향(사용자): 입력 확장(나이·성별×변수 상호작용), 음주는 15잔 상한+비음주 플래그, 단계 라벨 대신 연속형 혈압을 분포로 학습(M1-C). 결과 AUROC 0.724~0.728, 정확도 0.51~0.52로 변화 없음.

### 10/25 — 전처리 재설계(사용자 규칙), 체인 파이프라인

- 명세를 떠나 사용자가 정한 규칙으로 전처리를 다시 짬: 입력 17열 동일 투입, 거부 없이 상한만(음주 15, 활동 600), 나이·성별·BMI 결측 행만 제외, 음주 3열 결측은 0, 활동 결측은 flag 1 행 최빈값(0분), 가족력 0·나트륨 1·수면 0·당뇨 0, 공복혈당·심박수·교육은 최빈값, 허리둘레는 성별·BMI·나이 회귀로 추정, 대치 행도 학습에 포함.
- 체인(전 열 → sbp, 전 열+sbp → dbp, (sbp,dbp) → 단계)을 점 추정과 분포 두 방식으로 구현. 결과: 점 추정 단계 정확도 0.45(htn 거의 못 냄), 분포 경로 AUROC 0.72·정확도 0.50~0.52.
- 컬럼 영향력(순열 중요도): 나이 2.9 mmHg ≫ BMI 0.4~0.8, 성별 0.3~0.5, 나머지 0.0~0.2. 나트륨·수면·결측 수·교육은 0 → **사용자 결정으로 4열 제외**.
- 사용자가 테스트 파일로 19개 변형을 채점: 모두 AUROC 0.72 ± 0.003, 정확도 51~51.5%. 가중치 배수를 키우면 오히려 나빠짐.
- 정확도 상한 계산: 모델 확률대로 기대되는 최대 정확도가 0.519로 기준선과 같음. 실제 sbp를 알면 0.874, dbp를 알면 0.634로 뛰는 것을 확인 → "정보가 없어서" 못 오르는 것.

### 10/26 — 검정, 행 검증 보강, 정답률 탐색 3차례, 최종 모델

- 사용자 요청으로 입력 표현(표준화 / 문헌 기준값 중심 / 정상 범위 힌지 / 구간화 / 편차 등) 8가지를 5겹 교차검증으로 재검정하고, 제 결론을 모르는 별도 에이전트에게 같은 실험을 독립 구현하게 함. 두 결과 일치: 기준값 중심화는 표준화와 완전히 동일, 힌지 추가는 선형 모델에서만 0.03~0.04 mmHg 개선(LightGBM은 변화 없음). 이전 단일 분할 비교 코드의 결함(상호작용 표준화)을 발견해 수정.
- 사용자 규칙 추가: 허리둘레 필수, 대치 5개 이상 행 제외, 범위 밖 행 제외(BMI 14~50, 허리 50~150, 공복혈당 50~300, 심박 40~150; 뒤 둘은 임시값), 편차 중심을 문헌 기준값으로. 학습 1,002행·테스트 파일 260행 제외. 지표 변화 없음.
- **정답률 탐색 1차**: 단계 직접 다중분류 LightGBM, 규칙 최적화(클래스 가중, 나이대별), 연도 피처, 최근 연도 가중, 순서형 회귀, 앙상블. → **다중분류 LightGBM이 체인보다 교차검증 정확도 +0.010, AUROC +0.017로 일관되게 높음**. 나머지는 이득 없음.
- 상한 탐색: LightGBM 50설정, XGBoost 12, CatBoost 6, MLP 2, 스태킹 = 71가지 → 최고 0.520(잡음 범위). 가상 실험: 현재 혈압과 상관 0.6 이상인 "과거 혈압" 열이 있으면 0.6 도달(0.7이면 0.63).
- 사용자 결정: 데이터 추가 불가 → **다중분류 LightGBM을 최종 모델(M1-F)로 확정**. 학습·추론 CLI, 단건 고속 경로(p95 3.1 ms), 배치와의 동등성 검증, 테스트 41개.
- 테스트 파일 채점(사용자): 정확도 **52.0%**, AUROC 0.730(이전 최고 51.5%, 0.721).
- **2차 탐색**: 시드 배깅, 두 축 이진 합성, 회귀값 스태킹, 나이대별 모델, 테스트 입력 자기 학습 → 모두 잡음 범위 또는 악화.
- **3차 탐색**: 측정 오차를 반영한 소프트 라벨(σ=5에서 +0.0014, 간신히 신뢰구간 밖), 입력 잡음, dart·extra_trees, 계층 분류, 학습 곡선(데이터 2배로도 +0.3~0.5점), person_id 접두 문자(약한 신호, 제품 입력 부적합). 소프트 라벨 변형의 테스트 예측을 전달해 채점 대기.
- "normal을 빼고 세 단계만 학습" 제안 검증: 비normal 집단 안의 정확도 0.494 vs 4단계 모델 0.495로 동일, 전원 적용 시 0.25.

## 5. 현재 최종 모델 M1-F가 하는 일

### 5-1. 입력 → 출력 흐름

1. **입력** 15개: age, sex, bmi, waist_cm, alcohol_week, alcohol_per_day, binge, activity_minutes_week, activity_low_flag, family_htn, diabetes_flag, fasting_glucose, resting_hr (+ 음주 15잔 이상 플래그, 활동 600분 이상 플래그는 자동 생성). 혈압은 입력에 없음.
2. **행 검증**: 나이·성별·BMI·허리둘레 중 하나라도 없으면 예측 불가. 대치가 5개 이상이거나 BMI·허리·공복혈당·심박수가 범위를 벗어나도 예측 불가(사유를 note에 적음).
3. **결측 채우기**: 4절의 사용자 규칙 그대로(음주 0, 활동 0분, 가족력 0, 당뇨 0, 공복혈당 93, 심박 68, 허리는 회귀 추정).
4. **표준화·추가 데이터**: 연속형은 문헌 기준값(BMI 23, 허리 90/85, 공복혈당 100, 심박 100, 활동 150, 음주 14)에서의 편차를 표준편차로 나눔. 나이×변수, 성별×변수 상호작용을 더해 42열.
5. **LightGBM 다중분류**: 4단계 확률을 냄(합 1).
6. **단계**: 확률이 가장 큰 단계. 함께 **기여 요인**(그 단계를 올린 변수 상위 3개)을 냄.

### 5-2. 예시

입력: 52세 남성, BMI 27.5, 허리 95, 주 21잔·폭음, 운동 60분, 가족력, 공복혈당 104, 심박 72
출력: 단계 prehtn, 확률 normal 0.16 / elevated 0.05 / prehtn 0.40 / htn 0.39, 기여 요인 bmi(+0.16), alcohol_week(+0.10), resting_hr(+0.09)

### 5-3. 성능과 속도

| 지표 | 시간 분할 테스트 | 5겹 교차검증 | 사용자 테스트 파일 |
|---|---|---|---|
| 정확도 | 0.513 | 0.518 ± 0.006 | 0.520 |
| AUROC ≥140/90 | 0.716 | 0.731 ± 0.007 | 0.730 |
| 기준선(전부 normal) | 0.509 | 0.51 | 약 0.49 |

- 나이대별 정확도(시간 분할): 여 19~39세 0.90(기준선 0.90), 여 60세 이상 0.35(0.35), 남 40~59세 0.44(0.40). 젊은 층은 거의 normal이라 쉽고, 고령층은 네 단계가 고르게 섞여 어렵습니다.
- 단건 추론 p95 3.1 ms(기여 요인 포함), 0.2 ms(제외). 단건 경로와 배치 경로가 같은 값을 내는지 6,854행으로 검증(불일치 0).

## 6. 정답률이 0.52에서 멈추는 이유 (쉽게)

1. **모델이 쓸 수 있는 정보가 나이·체격·성별뿐**입니다. 순열 중요도에서 나이를 뒤섞으면 오차가 2.9 mmHg 늘지만, 그다음 변수는 0.4~0.8이고 음주·운동·수면·나트륨은 0입니다.
2. **같은 입력을 가진 사람들의 혈압이 넓게 퍼져 있습니다.** 모든 입력을 다 써도 sbp 오차의 표준편차가 13.8 mmHg인데, 단계 하나의 폭은 10 mmHg입니다. 고령일수록 퍼짐이 커서(20대 8~10, 70대 17) 60세 이상에서는 네 단계 확률이 거의 평평합니다.
3. **모델 자신도 그 이상을 기대하지 않습니다.** 모델 확률이 정확하다고 가정하고 계산한 최대 정확도가 0.52로, 실제 정확도와 같습니다. 즉 "더 잘 고르는 규칙"이 있는 것이 아니라 "고를 근거"가 없습니다.
4. **정보가 들어오면 바로 반응합니다.** 실제 sbp를 알려 주면 정확도 0.874, dbp를 알려 주면 0.634, 상관 0.6짜리 과거 혈압을 넣으면 0.594가 됩니다. 파이프라인이 고장 난 것이 아니라 입력이 부족한 것입니다.
5. 입력을 다르게 적는 것(표준화, 기준값 중심, 구간화, 편차, 힌지), 가중치를 바꾸는 것, 모델을 바꾸는 것(선형·LightGBM·XGBoost·CatBoost·MLP·앙상블), 규칙을 바꾸는 것(argmax·누적·가중·나이대별), 학습 집단을 바꾸는 것(normal 제외, 나이대별, 완전행만) 모두 같은 자리에 수렴했습니다. 이미 있는 정보를 다른 모양으로 넣는 일은 정보를 늘리지 못하기 때문입니다.

## 7. 0.6으로 가려면

- **과거 혈압**(이전 검진값, 가정 측정값): 현재 혈압과 상관 0.6이면 0.594, 0.7이면 0.628, 0.8이면 0.675(가상 실험). 가장 확실한 길이지만 데이터가 필요합니다.
- **복약 여부**: 지금은 전원 비복약 가정이라 약으로 조절된 사람이 낮은 단계로 들어가 있습니다. 라벨 자체가 정확해집니다.
- **사람당 여러 검진(종단 자료)**: 1번을 쓰려면 필요합니다.
- **검사 수치**(지질·신장 기능 등): 효과는 작을 것으로 봅니다(혈압 외 변수 전체의 기여가 작았음).
- 학습 데이터 양만 늘리는 것은 2배로도 +0.3~0.5점(학습 곡선).

## 11. 남은 선택지

- 최종 모델 코드·문서를 팀 저장소에 반영할지(현재 보류).
- 소프트 라벨(σ5) 변형을 최종 모델에 넣을지: 테스트 파일 채점 결과를 보고 결정.
- 임시값으로 둔 범위(공복혈당 50~300, 심박 40~150)의 확정.
- 제품 출력 형식: 단계 + 4단계 확률 + 기여 요인 중 무엇을 보여 줄지.
- 과거 혈압·복약 데이터 확보 가능성 재검토(0.6의 조건).
