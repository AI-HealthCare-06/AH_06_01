## 요약: 현재 임계값과 고IF 문헌의 관계

| 코드 | 현재 | 고IF 문헌이 가리키는 것 | 판정 |
|---|---|---|---|
| activity_low | <150분/주 | 선형(10 MET·h당 −6%), 임계값 없음 | 방향 일치, 경계는 관례 |

## 찾지 못한 것 / 확인 못 한 것

- 나트륨 4,000 mg 경계의 고혈압 OR; 폭음 단독 발생 위험; 연령 경계 문헌; 가족력 고IF 메타분석
