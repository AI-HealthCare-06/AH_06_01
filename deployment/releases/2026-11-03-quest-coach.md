# 퀘스트 알림·맞춤 운동 추천 릴리스

릴리스 브랜치: `release/1.7-quest-coach-20261103` · 기능 PR: [#39](https://github.com/AI-HealthCare-06/AH_06_01/pull/39).

최신 develop의 퀘스트 독려 알림, 알림창 진행도, 운동 취향 설문과 맞춤 운동 추천을 main으로 배포한다. 알림은 사용자가 켠 경우에만 동작하며, 추천은 가벼운 스트레칭부터 허용된 운동 목록 안에서 제공한다. 외부 AI 분석은 별도 동의 후 취향·생활습관과 운동 후보만 사용하며 이름·사진·혈압 측정값을 보내지 않는다. 연결 실패 또는 미동의 시 기본 추천을 제공한다.

운동 취향 설문은 최초 완료 시 100 EXP, 운동 완료는 하루 최대 세 번 각 60 EXP를 제공하며 중복 보상을 막는다. 기존 저장 데이터의 운동 상태는 안전한 기본값으로 초기화한다. 영상 전용 계정·사진·녹화 화면·합성 AI 응답은 포함하지 않는다.

## 검증

- 기능 PR과 develop 병합 CI: lint·format·프런트 단위 375개·빌드, 브라우저 전체 4분할, Android 컴파일 통과.
- 별도 서비스 E2E 6개, 식단·운동 API 단위 28개 통과. 외부 AI 호출은 모의 응답으로 검증했다.
- 릴리스 PR과 main 배포에서도 같은 CI를 다시 실행한다.

## 배포 및 호환성

1. 이 브랜치를 PR의 merge commit으로 main과 develop 양쪽에 병합한다.
2. main 커밋으로 기존 식단 Lambda 패키지를 갱신해 `/api/diet/exercise/recommend`를 연결한다. 기존 IAM·비밀값·데이터는 유지하며 코드 변경만 있는 CloudFormation 변경 세트를 검토한다.
3. main GitHub Actions에서 APK·웹·설치 페이지·서명된 OTA를 게시한다. 네이티브는 `1.7.0 (13)`을 유지하며 웹 버전은 실행 번호로 증가한다. 실제 버전과 main SHA는 공개 `release.json`을 기준으로 한다.
4. 기존 `1.5.0`, `1.5.1`, `1.5.2`, `1.7.0` OTA 채널의 서명·버전·출처를 확인한다. 새 DB 마이그레이션이나 OTA 채널 추가는 필요하지 않다.

문제가 생기면 기존 APK·채널을 보존하고, 수정 PR을 main에 병합해 더 높은 웹 버전으로 배포한다. 실제 모바일 알림 수신과 스피커·진동 등 기기 동작은 실기기 검증 범위를 별도로 기록한다.
